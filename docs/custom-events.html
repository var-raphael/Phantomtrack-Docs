Custom Events Tracking

Track button clicks, form submissions, and any user interaction on your website with optional callback support.

What are Custom Events?

Custom events let you track specific user actions beyond basic page views. Monitor button clicks, video plays, form submissions, downloads, or any interaction you care about.

What you can track:

  • Button clicks (CTA buttons, signup buttons, etc.)
  • Form submissions (contact forms, newsletter signups)
  • File downloads (PDFs, images, documents)
  • Video interactions (play, pause, complete)
  • E-commerce actions (add to cart, checkout started)
  • Any custom user interaction

Basic Usage

PhantomTrack gives you a global window.phantom.track() function. Use it anywhere in your JavaScript:

phantom.track('button_clicked');

You can also use the alias phantom.event() - they do the same thing:

phantom.event('button_clicked');

Simple Button Click Example

Track when a user clicks a button:

<button onclick="phantom.track('signup_clicked')">
  Sign Up
</button>

Adding Properties to Events

Track additional data with your events using properties. This is useful for context like product names, prices, or user selections.

phantom.track('product_viewed', {
  product_name: 'Blue T-Shirt',
  price: 29.99,
  category: 'clothing'
});

Properties Limit: Properties must be under 10KB (10,000 characters) total when converted to JSON.

Using Callbacks (Advanced)

PhantomTrack supports callbacks that execute after your event is tracked. This is perfect for actions that should only happen after successful tracking, like redirects or showing success messages.

Callback Function Signature

Your callback receives two parameters:

  • success (boolean) - true if tracking succeeded, false if it failed
  • result (object/error) - Response data on success, error object on failure

Basic Callback Example

phantom.track('purchase_completed', { amount: 99.99 }, function(success, result) {
  if (success) {
    console.log('Event tracked successfully!');
    window.location.href = '/thank-you';
  } else {
    console.error('Tracking failed:', result);
  }
});

Callback Without Properties

You can skip the properties parameter if you only need the callback:

phantom.track('signup_clicked', function(success) {
  if (success) {
    window.location.href = '/dashboard';
  }
});

Important: Callbacks are executed regardless of success or failure. Always check the success parameter before proceeding with critical actions.

Callback Use Cases

Safe Page Redirects

Ensure events are tracked before redirecting users to another page:

function handleSignup() {
  phantom.track('signup_button_clicked', {
    source: 'landing_page',
    plan: 'pro'
  }, function(success, result) {
    if (success) {
      // Event was tracked successfully, safe to redirect
      window.location.href = '/signup?plan=pro';
    } else {
      // Event failed but redirect anyway (optional)
      console.warn('Tracking failed, redirecting anyway');
      window.location.href = '/signup?plan=pro';
    }
  });
}

Form Submission with Feedback

Show a loading state while tracking, then provide user feedback:

function handleFormSubmit(event) {
  event.preventDefault();
  
  const submitButton = document.getElementById('submit-btn');
  submitButton.disabled = true;
  submitButton.textContent = 'Submitting...';
  
  phantom.track('contact_form_submitted', {
    email: event.target.email.value,
    subject: event.target.subject.value
  }, function(success, result) {
    if (success) {
      // Show success message
      document.getElementById('success-msg').style.display = 'block';
      event.target.reset();
    } else {
      // Show error message
      document.getElementById('error-msg').style.display = 'block';
    }
    
    submitButton.disabled = false;
    submitButton.textContent = 'Submit';
  });
}

E-commerce Purchase Tracking

Track purchases and proceed to checkout only after confirmation:

function initiateCheckout(cartData) {
  phantom.track('checkout_initiated', {
    cart_total: cartData.total,
    item_count: cartData.items.length,
    currency: 'USD'
  }, function(success) {
    if (success) {
      // Analytics tracked, proceed to payment
      window.location.href = '/checkout/payment';
    } else {
      // Failed to track but still allow checkout
      console.error('Analytics tracking failed');
      window.location.href = '/checkout/payment';
    }
  });
}

Show Notification After Tracking

Display a toast notification once the event is confirmed:

function addToWishlist(productId) {
  phantom.track('added_to_wishlist', {
    product_id: productId
  }, function(success) {
    if (success) {
      showToast('Added to wishlist!', 'success');
    } else {
      showToast('Action completed (tracking unavailable)', 'warning');
    }
  });
}

function showToast(message, type) {
  // Your toast notification logic
  const toast = document.createElement('div');
  toast.className = `toast toast-${type}`;
  toast.textContent = message;
  document.body.appendChild(toast);
  
  setTimeout(() => toast.remove(), 3000);
}

Download with Callback

Track file downloads and trigger the actual download in the callback:

function trackAndDownload(fileName, fileUrl) {
  phantom.track('file_downloaded', {
    file_name: fileName,
    file_type: fileName.split('.').pop()
  }, function(success) {
    // Download regardless of tracking success
    const link = document.createElement('a');
    link.href = fileUrl;
    link.download = fileName;
    link.click();
  });
}

Framework-Specific Examples

React

Track events in React components:

import React from 'react';

function SignupButton() {
  const handleClick = () => {
    window.phantom.track('signup_clicked', {
      button_location: 'header'
    }, (success) => {
      if (success) {
        // Navigate to signup page
        window.location.href = '/signup';
      }
    });
  };
  
  return (
    <button onClick={handleClick}>
      Sign Up
    </button>
  );
}

export default SignupButton;

Best Practices

✓ DO:

  • Use descriptive event names: signup_clicked, pdf_downloaded
  • Use underscores for multi-word events: add_to_cart
  • Keep event names under 100 characters
  • Add properties for context: product names, prices, categories
  • Test events in browser console first
  • Use callbacks for critical workflows (redirects, confirmations)
  • Always check the success parameter in callbacks
  • Handle both success and failure cases gracefully

✗ DON'T:

  • Include personal data (emails, names, phone numbers)
  • Use spaces in event names: use button_clicked not button clicked
  • Send properties larger than 10KB
  • Track every tiny interaction (focus on important actions)
  • Block user actions if tracking fails (UX first, analytics second)
  • Forget to handle callback errors

Advanced: Error Handling in Callbacks

Implement robust error handling for production environments:

function trackWithRetry(eventName, properties, onSuccess, onFailure) {
  phantom.track(eventName, properties, function(success, result) {
    if (success) {
      // Analytics tracked successfully
      if (typeof onSuccess === 'function') {
        onSuccess(result);
      }
    } else {
      // Analytics failed
      console.error('PhantomTrack error:', result);
      
      if (typeof onFailure === 'function') {
        onFailure(result);
      } else {
        // Default fallback: proceed anyway
        if (typeof onSuccess === 'function') {
          onSuccess(null);
        }
      }
    }
  });
}

// Usage
trackWithRetry(
  'checkout_completed',
  { total: 149.99 },
  function() {
    window.location.href = '/thank-you';
  },
  function(error) {
    // Log error but still proceed
    console.warn('Proceeding despite tracking failure');
    window.location.href = '/thank-you';
  }
);

Testing Your Events

Open your browser console (F12) and test tracking manually:

phantom.track('test_event', {
  message: 'This is a test'
}, function(success, result) {
  console.log('Success:', success);
  console.log('Result:', result);
});

Then check your PhantomTrack dashboard to see if the event appears in your custom events list.

Events appear in your dashboard within seconds. Refresh to see the latest data.

API Reference

phantom.track(eventName, properties, callback)

Parameters:

  • eventName (string, required) - Name of the event (max 100 characters)
  • properties (object, optional) - Event properties (max 10KB when JSON-stringified)
  • callback (function, optional) - Callback function(success, result)

Callback Parameters:

  • success (boolean) - true if event was tracked successfully
  • result (object|error) - Response data on success, error object on failure

phantom.event()

Alias for phantom.track(). Both functions work identically.

phantom.getSessionId()

Returns the current session ID as a string.

const sessionId = phantom.getSessionId();
