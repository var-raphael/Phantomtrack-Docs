Embed Dashboard with Iframe

Display your PhantomTrack analytics directly in your own admin panel or dashboard.

What is Iframe Embed?

Instead of using the PhantomTrack web dashboard or fetching data via API, you can embed the entire dashboard directly into your website using an iframe. This is perfect for:

  • Admin panels where you want analytics displayed alongside other metrics
  • Client dashboards where you need to show website performance
  • Internal tools that aggregate data from multiple sources
  • Custom layouts where you control the sizing and positioning

Basic Usage

Embed the PhantomTrack dashboard using a simple iframe. Just replace YOUR_TRACK_ID with your tracking ID:

<iframe 
  src="https://phantomtrack.xyz/embed?track_id=YOUR_TRACK_ID"
  style="width: 100%; height: 100vh; border: none;"
></iframe>

Example with a real tracking ID:

<iframe 
  src="https://phantomtrack.xyz/embed?track_id=track_fz3cmifh6b817mfx71l6my"
  style="width: 100%; height: 100vh; border: none;"
></iframe>

That's it! The dashboard will load with all your analytics data, charts, and metrics.

Custom Sizing

Adjust the iframe size to fit your layout:

Full viewport height:

<iframe 
  src="https://phantomtrack.xyz/embed?track_id=YOUR_TRACK_ID"
  style="width: 100%; height: 100vh; border: none;"
></iframe>

Fixed height (800px):

<iframe 
  src="https://phantomtrack.xyz/embed?track_id=YOUR_TRACK_ID"
  style="width: 100%; height: 800px; border: none;"
></iframe>

Responsive container:

<div style="width: 100%; max-width: 1200px; margin: 0 auto;">
  <iframe 
    src="https://phantomtrack.xyz/embed?track_id=YOUR_TRACK_ID"
    style="width: 100%; height: 700px; border: none; border-radius: 12px;"
  ></iframe>
</div>

Inside a card/panel:

<div class="card" style="padding: 20px; background: #fff; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
  <h2>Analytics Dashboard</h2>
  <iframe 
    src="https://phantomtrack.xyz/embed?track_id=YOUR_TRACK_ID"
    style="width: 100%; height: 600px; border: none;"
  ></iframe>
</div>

Integration Examples

React Component:

function AnalyticsDashboard() {
  const trackId = 'track_fz3cmifh6b817mfx71l6my';
  
  return (
    <div className="analytics-container">
      <iframe
        src={`https://phantomtrack.xyz/embed?track_id=${trackId}`}
        style={{ width: '100%', height: '100vh', border: 'none' }}
        title="PhantomTrack Analytics"
      />
    </div>
  );
}

Vue.js Component:

<template>
  <div class="analytics-container">
    <iframe
      :src="embedUrl"
      style="width: 100%; height: 100vh; border: none;"
      title="PhantomTrack Analytics"
    />
  </div>
</template>

<script>
export default {
  data() {
    return {
      trackId: 'track_fz3cmifh6b817mfx71l6my'
    }
  },
  computed: {
    embedUrl() {
      return `https://phantomtrack.xyz/embed?track_id=${this.trackId}`;
    }
  }
}
</script>

PHP:

<?php
$track_id = 'track_fz3cmifh6b817mfx71l6my';
$embed_url = "https://phantomtrack.xyz/embed?track_id={$track_id}";
?>

<iframe 
  src="<?php echo $embed_url; ?>"
  style="width: 100%; height: 100vh; border: none;"
></iframe>

Next.js Component:

export default function AnalyticsDashboard() {
  const trackId = process.env.NEXT_PUBLIC_PHANTOM_TRACK_ID;
  
  return (
    <div className="w-full h-screen">
      <iframe
        src={`https://phantomtrack.xyz/embed?track_id=${trackId}`}
        className="w-full h-full border-0"
        title="Analytics Dashboard"
      />
    </div>

}

Security & Best Practices

  • Keep your tracking ID secure - Don't expose it in public repositories
  • Use environment variables - Store track_id in .env files, not hardcoded
  • Use HTTPS - Always load the iframe over HTTPS for security
  • Set appropriate sizing - Ensure the iframe has enough space (minimum 700px height recommended)
  • Test responsiveness - Check how the iframe looks on mobile devices
  • Add loading states - Show a spinner while the iframe loads
  • Handle errors gracefully - Add error boundaries in React/Vue apps

Important: Anyone with access to your tracking ID can view your analytics. Only embed in authenticated areas of your site.

Advanced: Loading State Example

Show a loading spinner while the iframe loads:

<div style="position: relative; width: 100%; height: 100vh;">
  <!-- Loading spinner -->
  <div id="loading" style="position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%);">
    <div style="border: 4px solid rgba(99, 102, 241, 0.1); border-left-color: #6366f1; border-radius: 50%; width: 50px; height: 50px; animation: spin 1s linear infinite;"></div>
    <p style="margin-top: 16px; color: #6b7280;">Loading dashboard...</p>
  </div>
  
  <!-- Iframe -->
  <iframe 
    id="analytics-iframe"
    src="https://phantomtrack.xyz/embed?track_id=YOUR_TRACK_ID"
    style="width: 100%; height: 100%; border: none;"
    onload="document.getElementById('loading').style.display = 'none';"
  ></iframe>
</div>

Troubleshooting

Iframe not loading?

  • Verify your tracking ID is correct (should start with track_)
  • Check browser console for errors (press F12)
  • Ensure you're using HTTPS, not HTTP
  • Check if your browser is blocking third-party cookies
  • Try in an incognito/private window

Dashboard looks cut off?

  • Increase the iframe height (minimum 700px recommended)
  • Use height: 100vh for full viewport height
  • Check your container doesn't have overflow: hidden
  • Remove any max-height constraints on parent elements

Showing error page?

  • Confirm the track_id exists in your PhantomTrack account
  • Check the URL format: ?track_id=track_xxxxx
  • Make sure there are no extra spaces or characters
  • Verify your PhantomTrack subscription is active
